# 앨범 커버형(3번) 이미지·릴스

정방형 액자 안에 사진을 구아슈·수채화풍 그림으로 바꾸고, 그림 색을 뒤집어 위·아래 배경 띠로 쓰는 인스타 이미지·릴스 제작 방식입니다.
Python(cv2, numpy, scipy, Pillow)과 ffmpeg가 필요합니다.

## 구성
- 이미지 1080×1350, 영상 1080×1920. 가운데 840px 정방형 액자.
- 위 띠 = 그림 아래쪽 땅 색, 아래 띠 = 그림 위쪽 하늘 색. 두 띠가 갈리는 선은 그림의 땅·하늘 경계 높이와 같습니다.
- 상단에 인물 영어 이름(글자 사이를 벌려 액자 폭에 맞춤, 44px), 하단에 출처 라벨.

## 릴스 화면 구성(1080×1920, 위에서 아래로)
- **최상단**(액자 위, 한 줄 띄움): 내용 자막. 자막이 끝나면 마지막 3초 동안 제목 "오늘의(부산단디고딕 L) 트레일(부산단디명조 M)"이 나타났다 사라짐.
- **액자**: 가운데 840px 정방형 그림.
- **액자 아래**: 러너 이름(예: KILIAN JORNET, 액자 폭에 맞춰 글자 사이를 벌림).
- **맨 아래 작은 글씨**: 출처와 제목 한 줄(예: RICH ROLL PODCAST · 세계 최고의 트레일 러너, 그의 마음속으로). 보통 글자 간격, 액자 폭에 맞춘 크기.
- 이름·출처·자막 글자색은 뒤 띠 색에 따라 남색/크림색으로 바뀜.

## 그림 변환
- 하늘: 사진 색을 따 6개 층, 물결 변위, 층 물결선을 따르는 은은한 붓결. 회색기·블러 없음.
- 인물: 원본 실루엣을 또렷하게 따서 한 가지 짙은 색으로 칠함.
- 땅: 수풀 덩어리 + 보로노이 암석 면. 면 사이 어두운 틈·경계선은 그리지 않고, 잎 점은 수풀·면 가장자리에만 드물게 둠.

## 스크립트 (`scripts/`)
| 파일 | 역할 |
| --- | --- |
| `paint_jornet.py` | Jornet 사진 → 그림 + 1080×1350 이미지 |
| `paint_runner_sunset.py` | 노을 러너 사진(암석 지형) → 그림 + 이미지 |
| `*_norunner.py` | 전환 영상용: 인물을 뺀 그림과 인물 마스크를 `.npz`로 저장 |
| `video_base.py`, `video_brush.py` | 하늘 6개 층을 한 층씩 붓질로 칠하는 영상 |
| `video_transition.py` | 붓질 → 배경색 전환 → 인물 확대로 화면이 검게 찼다가 다른 인물로 바뀌는 영상 |
| `paint_cloudsea.py` | 구름바다 사진 → 그림 + 이미지, 개체 마스크(`layers.npz`), `SKY_LOOP=1`이면 하늘 고리 영상 |
| `video_frame_transitions.py` | 그림 3장이 쌓이고 흩어지며 이어지는 릴스 프레임(`frames`), 확인 시트(`reelsheet`, `build`) |
| `add_subtitles.py` | 릴스에 시간 지정 자막과 끝 제목 "오늘의 트레일"을 입힘 |

## 실행 순서(전환 영상)
1. `paint_jornet_norunner.py`, `paint_runner_sunset_norunner.py`로 `.npz` 생성
2. `video_transition.py`로 프레임(JPEG) 생성
3. `ffmpeg -framerate 30 -i f_%04d.jpg -c:v libx264 -crf 18 -pix_fmt yuv420p -movflags +faststart out.mp4`

## 참고
- 스크립트에는 작업 당시의 첨부 파일 경로(글꼴·사진)가 들어 있어 실행 전에 경로를 바꿔야 합니다.
- 글꼴(Wanted Sans Bold·Medium)은 `fonts/`에 포함했습니다. 원본 사진은 포함하지 않았습니다.
- 스크립트는 작업 중 바로 쓰던 형태라 정리되어 있지 않습니다.
